# Routine OS — نسخه 1.1.0

برنامه‌ریز شخصی فارسی برای مدیریت فعالیت‌های تکرارشونده، اهداف، تایم‌تریکر و تحلیل عملکرد؛ با ذخیره‌سازی کاملاً محلی در IndexedDB و قابلیت نصب به شکل PWA.

## اجرای توسعه

پیش‌نیاز: Node.js نسخه `20.9` یا جدیدتر.

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را در Chrome باز کن.

## اجرای نسخه نصب‌پذیر (PWA)

برای فعال شدن Service Worker و تست نصب، نسخه Production را اجرا کن:

```bash
npm run start:pwa
```

این دستور ابتدا Production Build می‌سازد و سپس سرور را اجرا می‌کند. آدرس محلی:

```text
http://localhost:3000
```

در Chrome دسکتاپ/Android از دکمه «نصب اپ» داخل برنامه یا منوی مرورگر گزینه Install app / Add to Home Screen را انتخاب کن. در iPhone/iPad با Safari صفحه را باز کن، Share و سپس Add to Home Screen را بزن.

**نصب روی گوشی با آدرس کامپیوتر:** برای نصب PWA در موبایل، سایت باید با HTTPS باز شود؛ `localhost` فقط روی همان دستگاه است. برای نصب روی گوشی از نسخه HTTPS میزبانی‌شده (مثلاً دامنه یا هاست دارای SSL) استفاده کن. بازکردن `http://192.168...` در شبکه محلی معمولاً برای Service Worker و نصب PWA کافی نیست.

## فرمان‌های آماده

- ویندوز: `START-WINDOWS.bat` برای توسعه، `START-PWA-WINDOWS.bat` برای نسخه نصب‌پذیر.
- macOS/Linux: `START-MAC-LINUX.sh` برای توسعه، `START-PWA-MAC-LINUX.sh` برای نسخه نصب‌پذیر.

## شروع کاملاً خالی

در نسخه 1.1.0 هیچ دسته‌بندی، برنامه، جلسه یا هدف نمونه‌ای ساخته نمی‌شود. فضای کاری در اجرای اول خالی است و باید دسته‌بندی‌ها و برنامه‌ها را خودت ایجاد کنی.

اگر قبلاً نسخه قدیمی را اجرا کرده‌ای، در اولین اجرای نسخه جدید، برنامه‌ها و جلسات نمونه قدیمی حذف می‌شوند. دسته‌بندی نمونه فقط زمانی حذف می‌شود که هنوز به داده شخصی باقی‌مانده‌ای متصل نباشد؛ داده‌های شخصی غیرنمونه حفظ می‌شوند.

## ذخیره‌سازی و حریم خصوصی

این نسخه Backend یا دیتابیس خارجی ندارد. تمام اطلاعات در IndexedDB همان مرورگر و همان Origin نگهداری می‌شود:

- با Refresh و بستن/بازکردن مرورگر باقی می‌مانند.
- بین دستگاه‌ها خودکار همگام نمی‌شوند.
- پاک‌کردن Site Data یا پروفایل Chrome می‌تواند آن‌ها را حذف کند.
- از بخش تنظیمات، نسخه پشتیبان JSON بگیر و در صورت نیاز بازیابی کن.

## تحلیل و نمودارها

- روند تعداد جلسات برنامه‌ریزی‌شده و تکمیل‌شده در هفته/ماه/سال
- توزیع زمان مفید ثبت‌شده بر اساس دسته‌بندی
- نمودار زمان تمرکز روزانه در هفته جاری
- شاخص‌های عملکرد، نرخ تکمیل جلسات سررسیدشده و میانگین زمان هر جلسه
- اندازه فونت بزرگ‌تر در محورهای نمودار، راهنما و Tooltip برای خوانایی بهتر
- در نبود داده، نمودار ساختگی یا داده نمونه نشان داده نمی‌شود و Empty State نمایش داده می‌شود.

## قابلیت‌های PWA

- Web App Manifest با نام، توضیحات و آیکون‌های 192/512 و Maskable
- Service Worker برای کش پوسته برنامه و فایل‌های استاتیک
- حالت standalone و امکان افزودن به صفحه اصلی گوشی
- کش فایل‌های لازم برای اجرای دوباره پوسته برنامه در شرایط آفلاین

PWA به‌معنای Push Notification در حالت بسته بودن مرورگر نیست. یادآوری فعلی برنامه هنگام باز بودن صفحه کار می‌کند؛ Push واقعی نیازمند Push Server و VAPID است.

## تکنولوژی‌ها

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Recharts
- Lucide React
- IndexedDB
- Web App Manifest + Service Worker
