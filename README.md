# Routine OS 1.1.0

Persian-first personal routine planner with IndexedDB local persistence, upgraded analytics, a clean first-run workspace, and installable PWA support.

- Setup and usage: [README_FA.md](./README_FA.md)
- Development: `npm install && npm run dev`
- Production PWA: `npm run start:pwa`

The application has no backend and stores data in the current browser origin's IndexedDB.
